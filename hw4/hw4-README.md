# Homework 4

This homework is intended to give you more exposure to sentiment analysis and dealing with raw data via web scraping. You will need the positive and negative word lists from the Lab 4, so either copy them over from Lab 4's repository or redownload them from <https://wustl.box.com/s/u5thu275xm4dxe3tevnlttl5d8he901u> and put them in `utility/data/` in your `hw4` folder.

A few instructions:

1. Make sure to clone this repo to your computer.
2. Then activate the Conda environment before starting the jupyter notebook
3. In your terminal, run the following commands:

```console
  conda activate cse2107
  jupyter notebook
```

When you're ready to commit and push:

1. Open terminal and navigate to the repo
2. Run the following commands:

```console
  git commit hw4*.ipynb -m "message"
  git pull
```

3. Make sure there aren't any merge conflicts. If there are any, resolve them using a code editor.
4. Finally, run the following command to push your changes:

```console
  git push
```
